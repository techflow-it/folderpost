Export / import configuration

      
    

    

      
Export

      

        Backs up all jobs (including credentials) as a JSON file — for example before an update, to restore the current state afterwards.
      

      

      
Import

      

        Choose a previously exported JSON file. Jobs with a matching ID are updated, new jobs are added.

Log retention

Language for logs and notifications

              

                Transfer log entries, notification e-mails and webhooks are written in this language. The language of the web interface is chosen per browser with the language button in the header.
              

              

                
                
              

      


      

              
Users & sign-in

              

                As long as no user has been created, the application is reachable without signing in. Once the first user exists, signing in is required and every change is attributed to that user in the change log.

Notifications

              

                If a file is moved to quarantine after several failed attempts, the application can report this on its own — by e-mail, by webhook, or both. To avoid repeated alerts for the same job, at most one notification is sent per job every 15 minutes.

Behaviour after installing

                

                
                
                


                
Install package

                

                  Upload a new package as a ZIP file. Configuration, logs and users are kept; a backup of the current state is made first. The application then restarts.
                

                
                
                

                  

                  
                

                

              


              
PDF processing (tools)

              

                Only needed for jobs that evaluate scanned PDFs with a QR code.
              

              
              


              
Configuration backups

              

                A copy is made automatically before every change (the last 10 are kept). When restoring, the current state is backed up first as well.
              

              

      


    

  







  

    

      
Manage categories

      
    

    

      

        Renaming affects every job in the category. Entering a name that already exists merges the two categories. An empty name removes the category assignment.
