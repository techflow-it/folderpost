Konfiguration exportieren / importieren

      
    

    

      
Export

      

        Sichert alle Jobs (inkl. Zugangsdaten) als JSON-Datei — z. B. vor einem Update, um den
        aktuellen Stand danach wieder einzuspielen.
      

      

      
Import

      

        Zuvor exportierte JSON-Datei auswählen. Jobs mit übereinstimmender ID werden aktualisiert,
        neue Jobs werden ergänzt.

Benutzer & Anmeldung

              

                Solange kein Benutzer angelegt ist, ist die Anwendung ohne Anmeldung erreichbar.
                Sobald der erste Benutzer existiert, wird eine Anmeldung verlangt und jede Änderung
                im Änderungsprotokoll dem Benutzer zugeordnet.

Benachrichtigungen

              

                Wird eine Datei nach mehreren Fehlversuchen in die Quarantäne verschoben, kann die
                Anwendung das von sich aus melden — per E-Mail, per Webhook oder beides. Um wiederholte
                Meldungen für denselben Job zu vermeiden, wird je Job höchstens alle 15 Minuten benachrichtigt.

Verhalten nach dem Einspielen

                

                
                
                


                
Paket einspielen

                

                  Neues Paket als ZIP hochladen. Konfiguration, Protokolle und Benutzer
                  bleiben erhalten; vom bisherigen Stand wird zuvor eine Sicherung angelegt.
                  Anschließend startet die Anwendung neu.
                

                
                
                

                  

                  
                

                

              


              
PDF-Verarbeitung (Werkzeuge)

              

                Nur nötig für Jobs, die eingescannte PDFs mit QR-Code auswerten.
              

              
              


              
Konfigurations-Sicherungen

              

                Vor jeder Änderung wird automatisch eine Kopie angelegt (die letzten 10).
                Beim Wiederherstellen wird der aktuelle Stand zuvor ebenfalls gesichert.
              

              

      


    

  







  

    

      
Kategorien verwalten

      
    

    

      

        Umbenennen wirkt auf alle Jobs der Kategorie. Wird ein bereits
        vorhandener Name eingetragen, werden beide Kategorien zusammengeführt.
        Ein leerer Name entfernt die Kategoriezuordnung.
